# Exercício 2 — Gestão acadêmica

Adaptação do exercício original para o Orange Data Mining.

As quatro bases serão importadas como CSV e relacionadas pelo widget `Merge Data`:

- `alunos.csv` por `id_aluno`;
- `disciplinas.csv` por `id_disciplina`;
- `cursos.csv` por `id_curso`;
- `matriculas.csv` como tabela principal.
