# Mineração de Dados

Materiais e exercícios da disciplina de Mineração de Dados.

## Organização

- `lista-01/`: primeira lista de exercícios;
- `lista-02/`: detecção de outliers com IQR;
- `lista-03/`: exercícios de Z-Score;
- `lista-04/`: exercícios de Isolation Forest;
- `trabalho-isolation-forest/`: trabalho com CSV fictício, notebook executado e apresentação;
- `environment.yml`: ambiente Conda do projeto.
